## 🚀 CÓMO DESCARGAR Y SUBIR

### Opción 1: Descargar como ZIP
1. Busca el botón "Download" o "Export" en esta plataforma
2. Descarga el proyecto como ZIP
3. Extrae el ZIP en tu computadora

### Opción 2: Copiar manualmente
1. Crea una carpeta: `registro-centros-trabajo`
2. Copia todos los archivos listados arriba
3. Mantén la estructura de carpetas

### Subir a GitHub:
```bash
git init
git add .
git commit -m "Sistema de registro de centros de trabajo"
git remote add origin https://github.com/TU-USUARIO/registro-centros-trabajo.git
git branch -M main
git push -u origin main
```

### Desplegar en Cloudflare:
1. Ve a https://dash.cloudflare.com/
2. Workers & Pages → Create → Pages → Connect to Git
3. Selecciona tu repositorio
4. Configura:
   - Framework: **Vite**
   - Build command: **npm run build**
   - Output directory: **dist**
5. Clic en "Save and Deploy"
