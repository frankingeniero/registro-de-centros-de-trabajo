## 🚀 EMPEZAR EN 3 PASOS

### 1️⃣ Instalar y Ejecutar

```bash
# Instalar dependencias
npm install

# Ejecutar el proyecto
npm run dev
```

Abre: http://localhost:5173

### 2️⃣ Configurar Firebase

1. Ve a https://console.firebase.google.com/
2. Crea un proyecto nuevo
3. Activa Firestore Database (modo prueba)
4. Registra una app web
5. Copia las credenciales
6. En la app, clic en "⚙️ Configurar Nube"
7. Pega las credenciales
8. Clic en "Conectar"

## 📤 SUBIR A GITHUB

```bash
# Inicializar Git
git init
git add .
git commit -m "Primera versión"

# Conectar con GitHub (reemplaza TU-USUARIO)
git remote add origin https://github.com/TU-USUARIO/registro-centros-trabajo.git
git branch -M main
git push -u origin main
```
